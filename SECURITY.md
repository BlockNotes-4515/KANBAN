# Security Policy

## Planora Security

Security is important to us. We appreciate responsible reports of security issues that may affect **Planora**.

## Supported Versions

| Version        | Supported |
| -------------- | --------- |
| 1.x            | ✅ Yes     |
| Older versions | ❌ No      |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not create a public GitHub issue** with sensitive details.

Instead, report it privately through the repository's **GitHub Security Advisories** or contact the project maintainer through the contact information available on the GitHub profile.

Please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Screenshots or proof of concept, if applicable
* Any suggested fix, if available

## Response

We will review legitimate security reports and, where appropriate, work to understand, fix, and document the issue.

Please allow reasonable time for investigation before publicly disclosing a vulnerability.

## Responsible Disclosure

We ask contributors and security researchers to avoid:

* Accessing or modifying other users' data
* Disrupting the application or repository
* Publicly disclosing vulnerabilities before they are addressed
* Performing actions that could damage the project or its users

Thank you for helping keep Planora secure.
