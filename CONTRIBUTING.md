# Contributing to Planora

Thank you for your interest in contributing to **Planora**. Contributions, suggestions, bug reports, and improvements are welcome.

## How to Contribute

1. **Fork** the repository.
2. **Clone** your fork locally.
3. Create a new branch:

   ```bash
   git checkout -b feature/your-feature
   ```
4. Make your changes.
5. Test your changes locally.
6. Commit your changes:

   ```bash
   git commit -m "Add: your feature"
   ```
7. Push your branch:

   ```bash
   git push origin feature/your-feature
   ```
8. Open a **Pull Request**.

## Contribution Guidelines

Please keep contributions:

* Simple and focused
* Responsive across devices
* Consistent with the existing UI
* Well-structured and readable
* Free from unnecessary dependencies

## Bug Reports

When reporting a bug, include:

* Description of the issue
* Steps to reproduce it
* Expected behavior
* Actual behavior
* Browser/device information
* Screenshots, if applicable

## Feature Requests

For new features, explain:

* What problem the feature solves
* How it should work
* Why it would improve Planora

## Code Standards

* Use meaningful variable and function names.
* Keep JavaScript modular and readable.
* Follow the existing CSS naming and formatting style.
* Avoid unnecessary code duplication.
* Test changes before submitting a Pull Request.

## Pull Requests

Please provide a clear description of:

* What was changed
* Why it was changed
* How it was tested

Keep Pull Requests focused on a single feature, improvement, or bug fix whenever possible.
